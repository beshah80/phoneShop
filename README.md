# Phone Shop Full Stack Website

This project is a full-stack phone shop website. The website is built using HTML, CSS, JavaScript, PHP, MySQL, and the XAMPP server. It includes multiple pages such as home, about us, products, and feedback.

### Features:
- Home page
- About us page
- Products page with various phone models
- Feedback page
- Login/logout functionality
- Two types of users: regular users and admins
    - Regular users can buy products and send feedback
    - Admins can edit products, manage orders, and view feedback
- Cart functionality to display the number of products in the customer's order
- Special discounts on selected products

### Technologies Used:
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP server

### How to Use:
1. Clone the repository
2. Install and configure XAMPP server
3. Import the database file provided (`database.sql`) into your MySQL database
4. Place the project folder inside the `htdocs` directory of your XAMPP installation
5. Start the Apache and MySQL services in XAMPP
6. Open your web browser and navigate to `localhost/PhoneShop`
7. Use the login/logout functionality to log in as a regular user or an admin
8. Explore the different pages including home, about us, products, and feedback
9. Regular users can buy products and send feedback
10. Admins can edit products, manage orders, and view feedback
11. Add products to your cart and enjoy special discounts on selected items

### Additional Information:
- This project is a full-stack e-commerce solution for a phone shop
- Feel free to explore the website and provide feedback
